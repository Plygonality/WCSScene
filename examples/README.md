# Synthetic examples

Every file in this directory was generated by `python scripts/generate_examples.py`.
None of them is a telescope observation.

| File | Contents |
| --- | --- |
| `reference.fits` | 96×80 pixel MEF. `SCI` has a rotated TAN WCS, 0.5 arcsec/pixel, ICRS. `DQ` uses `DQCONV=WCSSCENE_012`. |
| `reference_sources.ecsv` | Companion catalogue. Pixels are zero-based centres. `SRC-B` is the cross-highlight row. `SRC-BLANK` has no sky. `SRC-OUT` is outside the image. |
| `sip_distorted.fits` | Primary HDU with SIP terms that a corner-only affine plane does not reproduce. |
| `synthetic_no_wcs.npz` | Image and pixel positions with no WCS. Scientific placement must be refused. |
| `ngrst_catalog.csv` | Same synthetic rows under the NGRST-Discovery-Toolkit column names. |

`examples/roman_calibrated.asdf` is intentionally absent. A schema-factory ASDF is not an official Roman exposure, so it is not stored under that name.
